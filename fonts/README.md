## These are modified files, and that is allowed

The `.ttf` files here are **static instances cut from the variable originals** with
fontTools — iOS registers named instances of a variable font unreliably, so the app ships
static cuts and the website uses the same ones.

Cutting an instance is a modification, so OFL §3 (Reserved Font Names) is the clause to
check: it forbids a *modified* version from using a name the author reserved. **None of
these three fonts reserves a name.** Each OFL header reads simply "Copyright … The *X*
Project Authors" with no "with Reserved Font Name" clause — verified 2026-08-13 — so the
modified cuts may keep their original family names, which is why they still read
"Bricolage Grotesque", "Schibsted Grotesk" and "Martian Mono" in their name tables.

If any of these fonts is ever updated from upstream, re-check that clause before assuming
it still holds.

## What OFL still asks of us

- The licence travels with the font — done, in this folder.
- The fonts are not sold on their own. They are not; they are served as part of a free
  website for a free app.
- The OFL text itself may not be modified. It has not been.
